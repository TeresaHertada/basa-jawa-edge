Pemasangan dan penggunaan tanpa internet

Pada notebook, buka menu aplikasi di Edge atau Chrome. Pada Android gunakan menu Chrome → Instal aplikasi atau Tambahkan ke layar utama. Pada iPhone gunakan Safari → Bagikan → Tambahkan ke Layar Utama. Nama menu dapat berbeda menurut versi browser.

Tunggu indikator Siap offline, lalu tutup aplikasi, aktifkan mode pesawat, dan buka kembali. Model dan materi berjalan di browser. Penyimpanan browser dapat terhapus atau dibersihkan; periksa indikator sebelum menguji tanpa internet.

Untuk smartphone, buka aplikasi melalui HTTPS. Alamat HTTP dengan IP laptop hanya menyediakan pratinjau web. Alamat localhost pada notebook dapat digunakan untuk pengembangan PWA.

Teks yang Anda masukkan diproses di perangkat dan tidak dikirim ke server. Hanya hitungan kuis disimpan di browser ini.
